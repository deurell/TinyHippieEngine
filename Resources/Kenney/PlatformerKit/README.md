# Kenney Platformer Kit Subset

Curated GLB subset used by `Resources/Scenes/kenney_platformer.scene.json`.

Source: https://www.kenney.nl/assets/platformer-kit

Pack: Platformer Kit 4.1

License: Creative Commons Zero (CC0). See `Models/License.txt`.

Only the models needed by the sample scene are checked in here, plus the shared
`Models/Textures/colormap.png` referenced by the GLB files. The original pack
also includes FBX files and many more GLB models.
